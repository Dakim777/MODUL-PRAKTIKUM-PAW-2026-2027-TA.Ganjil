# Modul Praktikum Pengembangan Aplikasi Web (PAW)
### Institut Teknologi Sumatera (ITERA) — Tahun Akademik 2026/2027

Website resmi modul praktikum mata kuliah **Pengembangan Aplikasi Web (PAW)** Program Studi Teknik Informatika, Jurusan Teknologi Produksi dan Industri, Institut Teknologi Sumatera.

---

## 📌 Daftar Modul Pertemuan

- **Pertemuan 01:** JavaScript Dasar (Variabel, Kondisional, Loop, Fungsi, DOM Manipulation, Fetch API & Mini POS Task)
- **Pertemuan 02:** JavaScript Next Gen (ES6+, Scoping, Arrow Functions, Destructuring, Classes, Async/Await)
- **Pertemuan 03:** React Basics (Component Architecture, Hooks, State Management, Routing, Context API, Testing)
- **Pertemuan 04:** Python Dasar (Tipe Data, Struktur Kendali, Fungsi, List, Dictionary, Modul)
- **Pertemuan 05:** Python OOP (Class, Object, Inheritance, Encapsulation, Polymorphism, Abstraction)
- **Pertemuan 06:** Pyramid Framework (Scaffolding Cookiecutter, SQLAlchemy ORM, Alembic Migrations, REST API)
- **Pertemuan 07:** Basis Data + React Frontend (PostgreSQL, Service Layer, Marshmallow Schema, Fullstack Integration)

---

## 🚀 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) 16 (App Router + Turbopack)
- **Library:** [React](https://react.dev/) 19, TypeScript
- **Styling:** Vanilla CSS Modern (Design System tokens, glassmorphism, responsive)
- **Syntax Highlighting:** Prism.js & Shiki Light Theme

## 💻 Menjalankan Project Secara Lokal

1. **Clone repositori:**
   ```bash
   git clone https://github.com/Dakim777/MODUL-PRAKTIKUM-PAW-2026-2027-TA.Ganjil.git
   cd MODUL-PRAKTIKUM-PAW-2026-2027-TA.Ganjil
   ```

2. **Install dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan development server:**
   ```bash
   npm run dev
   ```

4. **Buka di browser:**
   Akses `http://localhost:3000` di browser.

5. **Build produksi:**
   ```bash
   npm run build
   npm run start
   ```
